### 🚀 Key Projects & Focus

- **DevSecOps Automation:** **[sec-scan](https://github.com/cymriccc/sec-scan)** — Production-grade Go security auditing tool featuring worker-pool concurrency, multi-format JSON/HTML reporting, pipeline risk gating (`--fail-on-risk`), and automated GitHub Actions CI/CD workflows.
- **Enterprise Queue Systems:** **[Q-Hop Management System](https://github.com/cymriccc/qhop-management-system)** — Cloud-connected queue management platform built in Java 17 and MongoDB Atlas with AES-128 security, real-time sync across kiosks/admin panels/TV displays, and automated Maven Fat-JAR distribution.
- **Procedural Graphics Engine:** **[Math Mosaic](https://github.com/cymriccc/math-mosaic)** — Interactive web application for rendering seed-based procedural tessellations using React 18, TypeScript, Tailwind CSS, and HTML5 Canvas API.
